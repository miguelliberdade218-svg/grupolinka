9️⃣  backend/backend/src/shared/firebaseAuth_MODERNIZADO.ts
    📁 Localização: backend/backend/src/shared/
    📝 Descrição: Middleware de autenticação modernizado (398 linhas)
    🎯 Objetivo: Sincronizar Firebase UID com database automaticamente
    🔧 Linguagem: TypeScript
    ✨ Destaque: Função syncUserWithDatabase() automática
    
    Exports principais:
    • verifyFirebaseToken (middleware principal)
    • syncUserWithDatabase (sincronização automática) ⭐
    • requireCapability (middleware de permissões)
    • requireAdmin (middleware admin-only)
    • AuthenticatedUser (interface TypeScript)
    • UserCapabilities (interface TypeScript)
    • createApiResponse, createApiError (helpers)
    
    Funcionalidades:
    • Token verification com Firebase Admin SDK
    • Automatic user creation se não existe
    • Firebase UID sync na primeira requisição
    • Capability calculation dynamic
    • Error handling completo
    • Logging estruturado
    
    Como usar:
    1. Copiar conteúdo para firebaseAuth.ts existente
    2. Ou criar novo ficheiro e atualizar imports em routes/auth.ts
    3. Middleware fica disponível em toda aplicação

1️⃣2️⃣  frontend/src/shared/components/SignupFlow.tsx
    📁 Localização: frontend/src/shared/components/
    📝 Descrição: Componente React unificado de signup (600+ linhas)
    🎯 Objetivo: Gerir signup de 3 tipos de usuários em 1 componente
    🔧 Linguagem: TypeScript (React)
    ✨ Destaque: Wizard com 6 passos, validação Zod
    
    Tipos suportados:
    • Cliente (4 passos)
    • Motorista (6 passos)
    • Gestor Hotel (6 passos)
    
    Passos do fluxo:
    1. Role selection (Cliente/Motorista/Hotel)
    2. Auth method (Google/Email)
    3. Basic info (nome, email, telefone)
    4. Specific data (condicional por role)
    5. Documents (upload para Motorista/Hotel)
    6. Confirmation (review e submit)
    
    Schemas Zod:
    • basicSchema - Validação dados básicos
    • driverSchema - Validação dados motorista
    • hotelManagerSchema - Validação dados hotel
    
    Recursos:
    • react-hook-form para state
    • Zod para validação
    • TypeScript para segurança
    • Lucide icons para UI
    • Progresso bar visual
    • Error handling
    • Loading states
    • Toast notifications
    
    Props esperadas:
    • onComplete (callback após sucesso)
    • onCancel (callback após cancelamento)
    • initialRole? (pré-selecionar role)
    
    Como usar:
    1. Copiar para frontendsrc/shared/components/SignupFlow.tsx
    2. Criar pages/signup-unified.tsx que importa e renderiza
    3. Atualizar routing para /signup → signup-unified
