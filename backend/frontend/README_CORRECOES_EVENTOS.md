## 🧪 Quick Reference - Validação

### Checklist de Testes
```
☐ Preço não é 0,00
☐ Amenities não está vazio
☐ Localização não é "não informada"
☐ Capacidade não é "-"
☐ Página de resultados mostra dados completos
☐ Console não tem erros
☐ DevTools mostra mensagens DEBUG
```

### DevTools - O Que Procurar
```
1. F12 > Console
   - Procure por "🔍 DEBUG"
   - Verifique valores extraídos

2. F12 > Network
   - Procure por /api/events/spaces
   - Verifique JSON retornado

3. F12 > Elements
   - Inspecione HTML
   - Verifique se dados estão lá
```
