```

```

```

├─ Clique em usuário
└─ Suspenda ou Reative
```

## 🎯 Ações Principais

### 🚫 Suspender Usuário
```
1. Vá em /admin/users
2. Clique no usuário
3. Clique "Suspender"
4. Escolha: Data de término (opcional)
5. Pronto! Usuário suspenso
```

### ✅ Aprovar Motorista
```
1. Vá em /admin/capabilities
2. Veja "Motoristas Pendentes"
3. Clique "Revisar"
4. Veja documentos
5. Clique "Aprovar" ou "Rejeitar"
6. Pronto!
```

### 💰 Confirmar Pagamento
```
1. Vá em /admin/payments
2. Veja "Pagamentos Pendentes"
3. Clique em pagamento
4. Clique "Confirmar"
5. Adicione notas (opcional)
6. Pronto! Pagamento confirmado
```

### 🏨 Gerenciar Hotel
```
1. Vá em /admin/hotels
2. Selecione hotel
3. Veja: Estadias, Receita, Reviews
4. Customize: Suspender, Ativar
5. Pronto!
```
